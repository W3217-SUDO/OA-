# 8.31 第13行阅读确认

- 模块：案件中心
- 原问题：案件里，平台费用的代理费和律所费用是有区别的，平台费用里的代理费只有一种类型，就是平台代理费。
- 新系统问题截图：`问题/_返工验收/8.31_第13行/source/24_row13_colC.png`。平台费用入口当前复用了普通“新增代理费”。
- 旧系统目标截图：`问题/_返工验收/8.31_第13行/source/25_row13_colD.png`。新增代理费窗口的费用类型下拉只有“平台代理费”。
- 旧系统源码：`Areas/Legal/Views/CaseFee/PartialView/Create.cshtml` 将“新增代理费”作为费用大类入口；费用明细由旧系统费用类型目录提供。截图明确了平台费用分支的唯一明细名称。

## 根因与整改范围

新系统把律所费用和平台费用共用了 `LEGACY_AGENCY_FEE_SUBTYPES`，前端列表菜单、详情空态、详情非空态、批量新增和历史草稿编辑都可能把平台代理费当成普通代理费；后端只校验费用大类，没有校验平台归属与代理费子类型的组合。

本行需要同时保证：

1. 平台费用的代理费入口仍显示“新增代理费”，但费用类型唯一为“平台代理费”，并自动带入。
2. 律所费用继续保留律师代理费、律师咨询费、律师培训费、律师见证费，不受影响。
3. 批量新增平台费用只能选择“平台代理费”。
4. 历史平台草稿中的普通“代理费”进入编辑时按“平台代理费”展示并保存。
5. 后端创建、修改和批量创建均拒绝“平台 + 普通代理费”，只接受“平台 + 平台代理费”；同时拒绝律所使用“平台代理费”。
