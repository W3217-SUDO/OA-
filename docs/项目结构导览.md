# 项目结构导览

## 三个核心模块

| 学习目录 | 真实源码目录 | 主要职责 |
| --- | --- | --- |
| `frontend/` | `apps/admin-web/` | React + TypeScript 网页端 |
| `backend/` | `apps/api-server/` | FastAPI、业务 API、权限和数据访问 |
| `aiagent/` | `apps/api-server/app/agent_mcp/`、`apps/api-server/app/areas/personal_agent/`、`apps/deepseek-harness-host/` | Agent 业务能力、工具协议和运行时 |

## 为什么保留 `apps/`

项目的 Docker、PowerShell、systemd、测试和发布脚本都已经使用 `apps/admin-web`、`apps/api-server` 和 `apps/deepseek-harness-host` 作为稳定路径。为了让目录更清楚，同时不破坏启动、构建、部署和测试，本次采用“导航目录 + 唯一源码目录”的方式，没有复制或移动代码。

因此：

- 需要学习或找入口时，从 `frontend/`、`backend/`、`aiagent/` 进入；
- 需要编辑代码时，只编辑对应的 `apps/` 真实源码；
- 不要在两个位置各维护一份同名代码；
- 根目录的 `docs/`、`scripts/`、`tests/`、`deploy/` 是项目级工具，不属于单一模块。

## 一条完整请求的阅读路线

```text
浏览器页面
  -> apps/admin-web/src
  -> API 请求
  -> backend/apps/api-server/app/areas 或 app/core
  -> 数据库 / 文件存储
  -> aiagent（需要助手时）调用工具和运行时
```

详细入口和推荐学习顺序见三个导航目录中的 README。
