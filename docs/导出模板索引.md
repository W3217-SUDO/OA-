## 5. 格式与后续使用约束

1. `.xls` 后缀不能证明其内容为 Excel 二进制。五份 HTML 文件分别为 S01、S03、S04 的两份文件和 S05；不得将其描述为原生 XLSX 或虚构工作表名。
