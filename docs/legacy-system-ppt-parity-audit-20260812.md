## 人员姓名统一规则

1. 人员可见名称只取系统用户维护的 `display_name`，允许中文、英文以及与登录账号相同的合法姓名。
2. 只有 `display_name` 为空时显示“姓名待维护”，不能把 username 当姓名回退。
3. username 仅用于登录账号列、权限主键、选择器 value，或明确标注“账号”的辅助信息。
4. 后端列表、详情、日志、附件统一返回对应的 `*_display_name`，前端不得自行猜测账号就是姓名。
