| 2.9 | 合同中心 → 我的应收款 | 案源人 | 查应收代理费、未到账垫付款 | 查询条件：合同、客户、日期等 |
| 2.10 | 我的合同（列表） | 全员 | 查询合同 | 合同名称、合同编号、合同类型、客户名称、案件编号、收费类型、合同日期、案源人、合同主体；列：官费支付/到账/未到账/亏损、代理费总额/到账/待收、其他金额、发票已开/应开/高开 |

## 03 调查大厅（P23–P37）

| # | 页面路径 | 角色 | 操作步骤 | 字段 / 要点 |
|---|---|---|---|---|
| 3.1 | 合同中心 → 我的合同 → 新建调查任务；调查大厅 → 我发布的调查任务 | 案源人/客户管理人 | 发布任务、查看已发布 | 同 2.7 |
| 3.2 | 调查大厅 → 待我分配的调查任务 → 新增子任务 | 调查组长 | 给调查员分子任务 | 任务名称、关联合同、调查员、开始/结束/截止日期、优先级、调查区域、备注；列表查询：调查编号、授权日期、权利人、调查区域 |
| 3.3 | 调查大厅 → 我的调查任务 → 选中 → 新增线索 → 暂存/提交 | 调查员 | 发现线索后录入 | 线索编号、调查员、客户、侵权方式、销售渠道、侵权产品、店铺链接/名称/ID、有无产品、产品链接、规模、调查地址、调查日期、生产商、主体信息、调查辅助员、权利类型、案源人、调查区域、来源、备注、附件。**一条线索只对应一个品牌、一个侵权产品** |
| 3.4 | 我的调查线索 → 待提交/待审核/已拒绝 → 修改 | 调查员 | 修改后暂存或提交审批 | 同 3.3 |
| 3.5 | 调查大厅 → 调查线索审核 | 案源人/客户管理人 | 审核线索（有风险意识） | 审核结果、意见（可能疑似冲突线索/案件、补充取证、并入案件） |
| 3.6 | 我的调查线索 → 待取证线索 → 取证 | 调查员 | 取证当日录入取证时间、公证机构 → 变“已取证” | 取证机构、取证日期、公证书号、发票号、仓库/库位、证物状态、说明 |
| 3.7 | 已取证线索 → 导出线索（Excel） | 调查员 | 给公证员填公证书号/发票号 | — |
| 3.8 | 已取证线索 → 生成案件（批量） | 调查员 | 选线索批量生成案件（文书、经办律师自动默认） | 客户诉讼地位、案由、案件阶段、经办律师、律师助理、案件类型、拟管辖法院；**一条线索只能生成一个案件；补充取证的线索应并入原案件** |
| 3.9 | 公证信息导入 → 公证书号仓库信息 | 调查员 | Excel 导入公证书号、发票号、仓库号、库位号 | Excel 文件 |
| 3.10 | 公证信息导入 → 公证书文件导入；导出交接清单 | 扫描文员 | 公证书+发票合并压缩、以公证书号命名、批量上传 | 文件（命名=公证书号） |
| 3.11 | 案件阶段“等待审核公证书” | 调查员 | 30 日内审核公证书要素（时间、地点、购买人、公证员、物品、数量、金额）→ 改为“新案待分配”；超 30 日系统自动改 | 审核结果、案件类型、拟管辖法院、意见 |
| 3.12 | 案件分给文书后自动任务 | 扫描文员 → 文书 | 交接公证书原件和发票原件，完成任务；5 日未重启视为交接完成 | — |
| 3.13 | 文档信息 → 调查文档 → 公证书电子件；公证信息导入 → 公证文件 | 文书 | 查公证书是否上传、可领原件的案件 | 公证书号 |
