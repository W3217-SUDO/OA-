# 用本地智能体连接 OA（MCP 接入说明）

适用对象：已被管理员开通权限的同事。开通后，你电脑上的智能体（Claude Code、Claude Desktop、Cursor 等）可以直接查询、办理 OA 里的业务，不用在网页里一项项点。

## 一、先看这几条（请务必阅读）

1. **权限和你的 OA 账号完全一致。** 你在 OA 里看不到、办不了的，本地智能体也看不到、办不了。
2. **令牌等同密码。** 不要发给别人，不要贴到聊天群、共享文档或代码仓库里。不用时请撤销。
3. **OA 里的数据会进入你电脑上的智能体，以及它所用的模型。** 请确认符合律所的保密要求，涉密案件请自行判断是否使用。
4. **普通的新增、修改、删除，智能体会先在对话里把要做的事列给你，你同意后它才执行；OA 收到后直接执行，不再二次确认。** 每一次操作都会在服务器上留下记录（谁、什么时候、通过什么、改了什么、改之前是什么），改错了管理员可以在 OA 的“系统管理 → 变更记录”里一键改回去。
5. **只有五类操作要在 OA 网页确认**：审批（审核/批准）、盖章与对外转交、付款与核销、开具或作废发票、退费登记到账。智能体调用这些接口时只会生成“待确认”，你需要到 OA 网页的智能体中心确认后才会执行。
6. **删除都是逻辑删除**，数据不会真的丢，管理员可以在 OA 的“系统管理 → 回收站”或“变更记录”里恢复。
7. 系统参数、系统配置、菜单、角色权限、用户授权、回收站、智能体技能和插件管理这类**系统管理接口不对外开放**，只开放业务接口。

## 二、谁可以用

- 系统管理员默认可以。
- 其他同事需要管理员在 **“用户管理 → 页面授权”** 里给你勾选：
  - “允许在自己电脑上用 MCP 连接 OA”：只能查询；
  - 再勾选“同时允许新增、修改、删除”：才可以办理业务。

没有勾选时，你在 OA 里看不到“电脑连接 OA”按钮。

## 三、生成令牌

1. 登录 OA，进入 **智能体中心**，点聊天框下方的 **“电脑连接 OA”**。
2. **先勾选这次要加载的业务**（见下表）。只勾你需要的，不要全选——选得越少，智能体越快、越准。
3. 填一个名称（例如“我的笔记本”），选有效期（7 / 30 / 90 天），点 **“生成令牌”**。
4. 令牌（以 `oamcp_` 开头）**只显示这一次**，关闭窗口就看不到了。点“复制命令”或“复制配置”，里面已经带好了你选的业务范围。

每人最多同时保留 5 枚有效令牌。令牌过期、被撤销、账号被停用，会立刻失效。

## 四、可选业务

连接地址里用 `biz=业务名` 选择，多个业务用英文逗号隔开，例如 `?biz=case,customer`。括号里是大致的接口数量。

| 业务名 `biz=` | 名称 | 大致接口数 | 包含的内容 |
|---|---|---|---|
| `customer` | 客户与合同 | 95 | 客户、联系人、律所、合同、利益冲突、人员基础选项 |
| `case` | 案件 | 121 | 案件查询统计、案件办理、开庭、归档、文档附件、人员基础选项 |
| `ipr` | 知识产权 | 181 | 知产案件、官文、年费、预警、文档附件 |
| `task` | 任务协作 | 49 | 任务指派、交接、协作沟通 |
| `investigation` | 调查取证 | 57 | 调查线索、取证公证 |
| `finance` | 财务 | 192 | 费用登记、回款认领、应收台账、结算提成、请款付款、开票、退费对账 |
| `seal` | 用印收发文 | 40 | 用印申请、印章管理、收发文 |
| `hr` | 人事组织 | 30 | 员工档案、部门、岗位 |
| `warehouse` | 仓库 | 14 | 仓库证物、库位、出入库 |
| `workbench` | 工作台与报表 | 57 | 待办汇总、报表、通知反馈、通用记录与搜索 |

接口数量会随系统更新略有变化；你看到的数量以“电脑连接 OA”窗口里显示的为准。

**不选业务**时，连接后只有 6 个入口工具，智能体需要先按分组查找接口，适合只是想试一下。

## 五、连接地址

```
https://huzhilawfirm.com/api/v1/mcp?biz=case,customer
```

请求头里带上令牌：

```
Authorization: Bearer <你的令牌>
```

## 六、各个智能体的配置方法

把下面的 `<你的令牌>` 换成刚生成的令牌，`biz=` 后面换成你要的业务。

### 1. Claude Code（命令行）

```bash
claude mcp add --transport http oa "https://huzhilawfirm.com/api/v1/mcp?biz=case,customer" --header "Authorization: Bearer <你的令牌>"
```

加完后在 Claude Code 里输入 `/mcp` 可以看到名为 `oa` 的连接。

也可以写进项目的 `.mcp.json`：

```json
{
  "mcpServers": {
    "oa": {
      "type": "http",
      "url": "https://huzhilawfirm.com/api/v1/mcp?biz=case,customer",
      "headers": { "Authorization": "Bearer <你的令牌>" }
    }
  }
}
```

### 2. Cursor

在 Cursor 的 MCP 配置（`~/.cursor/mcp.json`）里加入：

```json
{
  "mcpServers": {
    "oa": {
      "url": "https://huzhilawfirm.com/api/v1/mcp?biz=case,customer",
      "headers": { "Authorization": "Bearer <你的令牌>" }
    }
  }
}
```

### 3. Claude Desktop

Claude Desktop 的配置文件需要借助 `mcp-remote` 来连接远程地址（电脑上需要装有 Node.js）。编辑 `claude_desktop_config.json`：

```json
{
  "mcpServers": {
    "oa": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://huzhilawfirm.com/api/v1/mcp?biz=case,customer",
        "--header", "Authorization:${OA_AUTH}"
      ],
      "env": { "OA_AUTH": "Bearer <你的令牌>" }
    }
  }
}
```

保存后重启 Claude Desktop。

> 提示：配置文件里是明文令牌，请不要把这个文件发给别人或同步到公开位置。

## 七、怎么使用

**连上以后，智能体会先读“OA 使用指南”（内置技能）**：连接时 OA 会把这份指南交给它，里面写明了怎么找接口、怎么调用、写入前必须先问你确认、出错怎么处理，以及这次连接的业务范围和读写权限。你不需要自己教它。如果你的智能体没有自动读，可以对它说“先调用 oa_get_usage_guide 阅读使用指南”，或在支持提示（Prompt）的客户端里选 `oa-usage`。


连上后直接用自然语言说就行，智能体会自己找接口。例如：

- “查一下我名下进行中的案件有哪些”
- “看看这个客户有几个合同、合同金额合计多少”
- “给案件 XXX 新增一条开庭安排，时间是……”（智能体会先跟你确认内容，留痕可还原）

智能体调用接口的规则：

- 列表里每个接口都标了 **【查询】**、**【写入】** 或 **【删除】**。
- 调用前，智能体会先用 `oa_describe_tool` 取该接口的完整参数，再调用。
- 查询会直接执行；普通写入前，智能体会先在对话里把要改的对象、字段和新值列给你，你回复“确认”后才执行，做完会告诉你改了什么。
- 这五类操作只会生成“待确认”，到 OA 网页的智能体中心确认后才执行。

## 八、使用限制

| 项目 | 限制 |
|---|---|
| 请求频率 | 每分钟最多 120 次 |
| 写入频率 | 每分钟最多 30 次 |
| 令牌有效期 | 最长 90 天 |
| 同时有效的令牌 | 最多 5 枚 |
| 每次调用 | 都会被记录（时间、接口、参数；写入类记录完整请求），你可以在“电脑连接 OA”窗口里看到自己的调用记录；管理员在“系统管理 → 变更记录”里能看到所有人的操作日志和数据变更 |

## 九、常见问题

**提示 401（令牌无效、已过期或已撤销）**
令牌过期、被撤销或账号被停用了。回到“电脑连接 OA”重新生成一枚。

**提示 403，写着“不在这个连接地址选定的业务范围内”**
你调用的接口不属于连接地址里选的业务。把需要的业务加进 `biz=` 里，重新配置。

**提示 403，写着“该账号没有 MCP 写入授权”**
你的账号只开了查询权限。需要新增、修改、删除，请联系管理员开通“同时允许新增、修改、删除”。

**提示 403，写着“当前账号没有该菜单的操作权限”**
这是 OA 自己的权限限制：你的账号本来就不能做这件事，和令牌无关。

**提示 403，写着“属于系统管理类，不对个人访问令牌开放”**
系统参数、菜单、角色权限等管理类接口不开放，需要在 OA 页面里由管理员操作。

**提示 429**
调用太频繁，等一分钟再试。

**智能体说找不到某个接口**
确认连接地址里包含了对应的业务。不确定的话，让智能体先调用 `oa_list_tool_groups` 看有哪些分组。

**误删、改错了数据怎么办**
联系管理员，在 OA 的“系统管理 → 变更记录”里找到那次操作一键还原（删除的也可以在“回收站”里恢复）。

## 十、不再使用时

在“电脑连接 OA”窗口的令牌列表里，点对应令牌后面的 **“撤销”**，立刻失效。换电脑、离职交接、怀疑令牌泄露时，都请先撤销。
