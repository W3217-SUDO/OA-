1. 将案件详情文档树及相关操作中的“AI空间”显示为“案件智能体文件夹”，内部分类值继续使用 `AI空间`。

3. 在案件智能体中心增加“案件智能体文件夹”入口，按当前选中案件直达案件详情的该文件夹。
