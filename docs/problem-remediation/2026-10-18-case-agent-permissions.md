# 案件智能体权限隔离与案件底座预加载

## 原始需求

同时权限要做好 案件智能体只能操作这个案件里的东西 不能越权 同时 要先把案件信息的数据底座提前给案件智能体 而不是还需要提高 ，同时 案件智能体也要读取这个对话这个人系统权限 也不能越权操作

## 分流结论

这是明确的新权限与上下文能力需求，旧系统代码不适用。本次按当前新 OA 的案件智能体、MCP 工具网关和登录权限链路整改。

## 修改与验收映射

- 案件工具调用必须明确当前案件范围，不能访问其他案件或无法证明归属的目标。
- 人工确认必须重新使用当前登录人的案件能力，不能用无条件的工具权限替代系统权限。
- LangGraph 私有线程在读取状态时预置当前用户有权查看的案件快照，并继续按案件、用户、智能体和会话隔离。
