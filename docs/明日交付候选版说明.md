# 2026-07-17 明日交付候选版说明

## 交付结论

本候选版可以用于本地 Docker 演示、核心业务验收和受控服务器部署准备。它不能被描述为“220 个叶子页面已经全部逐页完全复刻”：当前全部路由均可解析，核心业务具备端到端验收，但仍有页面尚未完成原系统逐按钮、逐弹窗和逐像素举证。

## 交付前必须全部通过

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\verify-delivery.ps1
```

成功标志必须同时包含：

- `VERIFY_LOCAL_OK`
- `SMOKE_API_OK: 17 groups passed`
- `SMOKE_CLEANUP_OK: no test data remained`
- `VERIFY_DELIVERY_OK`

脱敏源码交付包可用以下命令重新生成；目标目录必须是源码目录外、本机磁盘上的绝对路径：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\export-delivery-source.ps1 -TargetDirectory "C:\交付目录\申浩协作平台_候选版" -CreateZip
```

脚本会排除真实环境文件、业务数据和附件、数据库导出、Docker 镜像、备份、日志与私钥，并为包内文件生成 `SHA256SUMS.txt`。源码 ZIP 不承载业务数据；业务数据必须使用独立迁移流程并通过加密通道传输。

生产服务器还必须执行：

```bash
chmod 600 .env.production
./deploy/preflight-production.sh .env.production
```

## 已证明范围

- React + TypeScript 网页端、FastAPI、PostgreSQL、Redis、Celery、MinIO、Nginx Web 六服务可构建和启动。
- 265 个菜单节点、220 个叶子路由结构覆盖为零遗漏。
- 17 组核心业务接口端到端流程通过并清理全部测试数据。
- 管理员保持全所、全菜单和全部字段权限。
- 合同、案件、任务、财务、发票、结算、调查、公证、收发文、用印、人事、仓库、报表和审计的核心专用流程已有真实接口门禁。
- “我发起的任务”“我接受的任务”“我协作的任务”已有独立原站结构门禁；协作页费用和案件批量操作已按原站二级菜单接入真实接口。
- 生产环境拒绝默认管理员密码、占位密钥和演示业务数据；空库管理员使用私有一次性强密码初始化。
- 备份在停写窗口内生成，配置不落盘插值秘密，全部产物有 SHA256；迁移包排除环境文件、私钥和旧备份。

## 尚未证明范围

- 并非全部 220 个叶子页面都已有原系统真实数据下的视觉、按钮、弹窗和接口证据。
- 部分原系统页面因当前账号下无业务行，只能证明空状态和静态脚本结构，不能证明所有有数据分支。
- 当前单机部署没有 Alembic 版本化迁移，不能宣称支持多副本无停机升级。
- Caddy 配置已提供模板，但真实域名、DNS、证书签发和公网防火墙必须在目标服务器验收。
- Dify 和微信小程序仅保留复用 API 架构，不属于本次网页候选版完成范围。

## 服务器上线顺序

1. 将源码/镜像与业务备份放入受控目录，生产环境文件通过独立加密通道传输。
2. 运行 `preflight-production.sh`，任何失败都不得继续。
3. 先在隔离服务器完成一次恢复演练并核对数据库、附件和对象存储。
4. 启动生产 Compose，仅在本机回环地址暴露 Web。
5. 按 `deploy/Caddyfile.example` 配置真实域名 HTTPS。
6. 运行健康检查、登录、只读抽查和最近日志检查。
7. 首次登录后立即轮换一次性管理员密码。
