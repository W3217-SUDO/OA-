# AI 智能文档权限与审计整改（2026-07-28）

## 已完成代码

- 关联业务的智能文档以当前关联记录的可见范围为准；创建人不再能在记录转交或撤权后继续读取、下载、重试、编辑、确认、回写或删除。
- 关联业务的写操作还要求负责人、部门负责人或管理员权限；未关联业务的个人草稿仍只允许创建人或管理员操作。
- 已人工确认或已回写附件的任务返回 409，不能删除。删除未确认任务保留创建历史并新增“删除智能文档任务”审计事件，避免工作流、确认信息和附件断链。
- 列表接口返回每项 capability；前端仅显示当前用户可办的写操作，保留有阅读权限用户的 DOCX 下载入口。
- 操作列固定在右侧，表格横向宽度为 1760，防止操作列遮挡关联业务链接。

## 自动化证据

- API 冒烟新增非客户证物关联文档撤权场景：原创建人被撤权后，列表、下载、重试、编辑、确认、回写和删除均被拒绝。
- API 冒烟验证已人工确认任务删除返回 409。
- 静态审计新增 `AGENT_DOCUMENT_SCOPE_AUDIT_OK`，覆盖关联范围、删除审计、前端 capability、右侧固定操作列和撤权测试。

## 仍未证明

尚未在浏览器分别以只读共享者、撤权创建人、负责人和管理员验证按钮可见性及公证/证物关联详情跳转。后续必须以页面创建的临时数据完成并精确清理，不把自动化结果视为页面验收。
