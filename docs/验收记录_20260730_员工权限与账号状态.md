# 员工权限与账号状态修复记录

## 已完成

- 员工修改弹窗以系统账号的最新角色、资料和合同审批资格为准回显，避免人事档案旧值覆盖实际权限。
- 登录账号启用状态可在员工修改弹窗中直接调整，并与员工在职、离职等人事状态分离。
- 员工列表与修改弹窗统一读取系统账号真实启用状态。
- 关闭账号后，登录接口和已有令牌访问均由后端 `current_identity` 拒绝；正式离职或停用仍通过“办理状态”记录原因和生效日期。

## 已验证

- CodeGraph 已检查人事页面、系统用户接口、认证依赖和人事状态流转的影响范围。
- 前端生产构建、Python 编译、菜单覆盖审计通过。
- 测试站 Web、API、Worker、PostgreSQL、Redis、MinIO 全部健康，外部 `/health` 返回 200。
- 页面确认权限字段能够回显，登录账号开关可操作且不再处于禁用状态。

## 仍未证明
