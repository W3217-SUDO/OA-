# 案件提成生命周期整改记录（2026-09-14）

## 用户原始问题

> 案件里根据代理费新建的提成直接流转到了财务中心-内部费用-内部提成待审核，但是这个案子里面的这笔到账既没有结算也没有归档，他应该在内部提成待结算里面，如果后面结算完完成，就进入内部提成-待归档，直至归档完成，这笔提成费用才能出现在财务内部提成-待审核里

## 专业定位

- VibeHub 已调用。采用“状态（State）”用于描述提成所处业务阶段；“质量门禁”不是本业务含义，本次不采用。
- 本问题属于业务状态机及前置条件校验缺失：内部提成应由到账结算状态与案件归档状态共同派生当前阶段，任何列表或审批接口都不得绕过前置状态。

## 状态规则

1. 来源代理费没有对应已完成结算：`待结算`。
2. 来源代理费结算完成、案件未归档：`待归档`。
3. 来源代理费结算完成、案件已归档或亏损归档：`待审批`。
4. 审批通过、驳回、付款、作废等后续状态保持现有财务流程，不再由前置事实反向覆盖。
5. 结算回退或案件解档时，尚未进入审批后续状态的提成必须回退到对应前置阶段。
