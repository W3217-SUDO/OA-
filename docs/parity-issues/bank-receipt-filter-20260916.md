# 各银行回款列表分流

用户原文：z这个里面的数据你按照这个筛选出来每个银行的

唯一截图 codex-clipboard-4e1598f4-c49c-46a6-8783-0738af405a41.png：普通回款管理下工行、中信、中行入口被框选，当前招商高亮；主表整块被框选，显示交易日期、付款人、金额、流水号及备注。诉求为各银行入口只列对应银行数据。截图本身不能判断每条的真实银行，以 bank_source 为准。

旧系统 FAM/AR/CMB/PaymentService.GetPaymentList 使用 CMB.PaymentDao 查询独立银行数据；前面 Process 按招行原表建记录。新查询 queriesActions.load 对所有银行调用无参数 incoming-payments，后端无 bank_source 参数，shownIncoming 仅按认领/分配状态分支，银行页面落回全部数据，因此四个入口混显。

只读线上归属统计：工行类标记含工行/工行883/申浩工行；中信类含中信/中信银行/中信_人民币/申浩中信；中行类含中行/恒达中行；另有7条银行标记为空。无需修改交易数据。

整改：银行路由向服务端传对应 bank_source，服务端按实际银行名称及旧标记过滤后再汇总；前端切换/刷新期间也按同样规则限定列表。综合管理不传银行条件，继续保留全部有权记录；未知银行不归入任意银行。沿用当前用户数据权限及搜索。

VibeHub 已运行“数据筛选”，无可靠词条。按直接问题规则只生产构建、语法及运行健康检查；不进行导入或业务验收，发布后待用户验收四家银行的列表。
