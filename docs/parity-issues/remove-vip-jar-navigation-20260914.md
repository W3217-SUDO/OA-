# 删除两处多余菜单入口

## 原文与截图
> 我标注的是多余的 删除掉

- 1475d4aa-1f1a-4b11-a11e-e8c42c3c888b：事务中心展开，红框为 VIP任务。
- a2dc3876-d29a-4494-82ba-60a13abbdf38：财务中心展开，红框为 JAR交案费管理。
- 用户明确指定删除菜单入口，无需旧系统推断；业务数据和其他入口不在删除范围。

## 定位与修改
App.tsx 默认 menuItems 含 vip-tasks、finance-jar；configuredMenuItems 又根据服务器导航配置重建菜单。只删默认项会在服务器返回配置后重新出现。
删除两处默认项，并在服务器配置转为用户导航时排除相同键，使左侧菜单及共用菜单的导航、搜索同步移除。
后端和数据库不涉及：无需删除已有任务或费用、无需数据库迁移。
VibeHub 核对 sidebar，词条为左侧栏布局。
