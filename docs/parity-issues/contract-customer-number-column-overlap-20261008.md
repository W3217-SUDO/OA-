# 合同中心客户编号列内容溢出

## 基本信息

- 状态：整改中
- 页面位置：合同中心 -> 我的合同/部门合同/公司合同，合同查询列表
- 前端入口：`?page=contract-mine`、`?page=contract-dept`、`?page=contract-company`
- 对应字段：客户编号；相邻字段为签订日期、客户名称
- 问题来源：用户于 2026-10-08 提供线上截图 `codex-clipboard-1f888549-2926-456e-83d3-63c5cd69723f.png`

## 新旧系统对比

### 线上新系统现象

截图中客户编号（例如 `HZKH...`）从自身列继续绘制到签订日期列，部分行与相邻日期、客户名称文字重叠。列头和数据列的边界不一致，长编号无法在列内截断。

### 旧系统/既有对齐要求

合同列表属于旧系统对齐页面，客户编号应保持在“客户编号”列内；超过列宽时显示省略号，完整值通过已有的链接悬停标题查看，不得覆盖相邻字段。仓库既有合同列表布局记录也明确要求客户编号链接受单元格宽度约束，本次属于该规则回归。

## 根因定位

- `apps/admin-web/src/contract/ContractList.tsx` 使用固定表格布局，但客户编号通过 Ant Design `Button` 链接渲染。
- `apps/admin-web/src/contract-center.css` 原先只限制链接自身的最大宽度，表格数据单元格仍允许内容溢出，且链接为 `inline-block`，长编号可能突破单元格边界。
- 因此这是前端布局约束缺失，不是客户编号生成或查询数据错误。

## 整改内容

- 为合同列表表格数据单元格和合计单元格增加 `overflow: hidden`，防止任意长文本绘制到相邻列。
- 将合同关联链接改为占满当前单元格宽度的块级元素，并启用 `box-sizing: border-box`、省略号和单行裁切。
- 保留链接点击进入客户详情的行为，未修改客户编号、客户关联和查询逻辑。
