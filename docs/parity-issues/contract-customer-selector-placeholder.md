# 合同新建：客户选择字段提示语

- 状态：已修复，待本地页面验收
- 发现来源：主动对齐审计，结合合同新建页面源码检查
- 前端页面：合同中心 -> 合同新建，路由 `contract-new`
- 前端字段：客户选择字段，组件 `ContractCreateWizard`，字段 `customer`
- 页面位置：合同新建向导第 1 步“合同基本信息”

## 旧系统对照

旧系统在客户选择位置明确提示用户输入客户名称关键字后再选择已登记客户。该字段属于已登记客户选择，不应让用户误解为可直接录入任意客户名称。

## 新系统问题

新系统客户选择控件的提示语存在编码异常，无法清晰表达“输入关键字并从已登记客户中选择”的操作要求，容易导致用户误以为可以自由录入客户名称。

## 根因定位

问题定位到前端文件 `apps/admin-web/src/contract/ContractCreateWizard.tsx` 的客户 `Select` 控件 `placeholder`，不是后端客户解析或权限逻辑问题。

## 整改情况

已将客户选择字段提示语修正为：`输入客户名称关键字后选择`。客户值仍通过客户记录 ID 提交，未放宽后端客户登记校验。
