- `fragments/SH/source/`、`source-final/`、`source-v2/`、`source-v3/`：SH 本地已有源码片段，分别保留来源目录，不合并成新项目。片段的原始、重建或反编译来源尚未完整证明，不能称为完整原始源码。
- 实际读取的本地绝对来源路径逐项记录在 `manifest.json`。原件只读，没有将归档修改反写到源目录。
- 本轮未从 ZIP 导入或解压第二份。根据主会话转交的 B 只读对比，同一 B allowlist 下主站 2,047 个路径无增减，但 15 个源码文件大小不同，其中 Razor 11 个、JavaScript 2 个、控制器 1 个、项目文件 1 个，因此本地与 `D:/GD.CRM.source-20260812.zip` 不等价。两者项目文件哈希记录于 manifest。

- ZIP 大小为 487,982,940 字节并混有业务文件，严禁整体上传。本归档不声明完整覆盖该 ZIP，也不声明包含全部历史系统源码。
- 项目引用的五个兄弟项目缺失，未尝试补齐；Compile 路径存在 `IPRAreaRegistration` 与 `IprAreaRegistration` 大小写差异，实际项目项与磁盘路径分别记录在 manifest，未改写原项目引用来伪造完整性。

## 公开脱敏规则

- 默认拒绝，仅纳入审核范围内的 C#、项目定义、Razor、自有业务脚本和必要静态资源；文件清单可由 `manifest.json` 逐项核对。
- 不进入 `sfhc`、运行目录、测试目录、传输目录、附件、上传、业务数据、备份、依赖和构建目录，不跟随 reparse point、junction 或符号链接。
- 目录名以 `.bak` 结尾的来源属于备份源码，按 `bak_source_backup` 排除。本轮按既有 manifest 路径和归档哈希逐个剔除 62 个已复制备份文件，未修改原件；剩余 3,679 个来源文件保持此前归档哈希，不以强制暂存或忽略规则例外重新纳入。
- 不包含数据库、数据库导出、业务附件、编译 DLL、EXE、PDB、私钥、证书、签名密钥、依赖包及运行时。排除统计不记录被排除业务文件的名称或内容。
- 二进制静态资源仅纳入两个 GD 项目根目录的 `favicon.ico` 候选图标，仍须独立复核；没有收集其他位图、照片或可能属于业务附件的图片，不因缺少这些图片扩大本次归档。
- 真实 XML 配置不原样复制；对应的 `.config.example` 通过 XML 解析生成，保留结构和安全字段标签，其余属性值、正文和注释不携带原始配置值。这些文件是不可直接运行的结构模板，不是生产配置。
- 对所有选中的文本源码执行本任务的离线硬编码凭据及业务数据规则检查，包含全部选中 C#、JavaScript 和 Razor。可识别敏感字面量、凭据格式、手机号、身份证号、邮箱及部分业务编号仅在归档副本置换为 `REDACTED_ARCHIVE_ONLY`，原件不变。
- 置换采取保守规则，可能包含误报；文件前后哈希、置换规则和源行号记录于 `sanitization.json`，不记录值或匹配片段。未改变文件保持原始字节和编码，新增清单、说明及 XML 模板采用 UTF-8。
